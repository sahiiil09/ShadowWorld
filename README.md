# Shadow World

Realtime Firebase attendance and member management web app.

## Files

- `index.html`
- `style.css`
- `script.js`
- `firebase.js`
- `assets/`

## Deploy on GitHub Pages

Upload all files to your GitHub repository, then enable:

Settings → Pages → Deploy from branch → main → root

## Firebase Rules for testing

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```
